# Inline Ask — Releases

Public download + auto-update host for **Inline Ask**, a Spotlight-style global-hotkey AI assistant for macOS and Windows.

- Download the latest build from the [Releases](https://github.com/Inline-Ask/inline-ask-app/releases) tab.
